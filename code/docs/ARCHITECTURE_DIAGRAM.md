## 🎯 优化约束模型

```
线性规划模型 (MathProg 表示法)

Maximize:
    Σ_p budget(p)                  // 最大化总消耗规模

Subject To:
    1. Σ_p budget(p) ≤ B           // 预算约束
    
    2. Σ_p ( revenue_current(p) 
       + budget(p) × ROI(p) × multiplier(p) )
       ≥ Σ_p ( spend_current(p) 
       + budget(p) ) × kpi_target   // ROI约束
    
    3. budget(A级) ≤ current(A级) × 0.50   // A级上限
    
    4. budget(B级) ≤ current(B级) × 0.20   // B级上限
    
    5. budget(C级) ≤ current(C级) × 0.10   // C级上限
    
    6. budget(p) ≥ 0, for all p    // 非负约束

Solved by:
    PuLP + CBC (开源求解器)
    
Complexity:
    ~150个决策变量 × 5-6个约束
    求解时间：2-5秒 (商用求解器可<1秒)
```

## 🔍 风险预警机制

```
实时监控三个维度：

【维度1】产品能力下滑
    └─检测：最近3天 D1 < 历史平均 D1 × 90%
    └─措施：自动降权，建议缩减预算
    
【维度2】流量异常波动
    └─检测：当日消耗偏离平均值 > 2σ（标准差）
    └─措施：告警，建议检查媒体侧
    
【维度3】月度ROI预警
    └─检测：预测月末 ROI < KPI 目标 - 3pp
    └─措施：建议缩减投放，保证达标

预警级别：
    🔴 HIGH   - 需要立即行动
    🟠 MEDIUM - 需要关注
    🟡 LOW    - 信息提示
```

## 📊 关键指标计算公式

```
【D1回收率】
    D1_rate = 首日广告收入 / 消耗金额
    范围：0% - 150%+（取决于产品质量）

【30日倍率】
    M30 = 30日累计回收 / 首日回收
    标准值：1.44（表示首日回收会增长到1.44倍）

【达标D1】
    target_D1 = KPI目标 / M30倍率
    例如：KPI=105%, M30=1.44 → target_D1=72.9%

【产品分级】
    A级：D1 ≥ target_D1 + 30pp
    B级：D1 ∈ [target_D1-20pp, target_D1+30pp)
    C级：D1 < target_D1 - 20pp

【月度ROI】
    ROI = 当月累计回收 / 当月累计消耗
    约束：ROI ≥ KPI_target（硬约束）

【ROI倍率（动态）】
    if 剩余天数 > 20:     倍率 = 1.44 (完整D30)
    elif 剩余天数 > 7:    倍率 = 1.38 (约D7)
    elif 剩余天数 > 3:    倍率 = 1.29 (约D3)
    else:                倍率 = 1.00 (仅D1)
    
    物理意义：月初投的钱有完整回收窗口
              月末投的钱回收窗口短（只能计D1）
```
