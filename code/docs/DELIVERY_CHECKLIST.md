## 🔧 常见问题速解

### Q1: 如何修改KPI目标？

```python
# 改为100%的KPI
system = IntelligentBudgetSystem('data.csv', kpi_target=1.00)

# 改为110%的KPI
system = IntelligentBudgetSystem('data.csv', kpi_target=1.10)
```

### Q2: 为什么预算没有完全分配？

**可能原因**：
1. ROI缺口大，需要保留安全边际
2. 所有产品都是C级，约束限制
3. 优化器认为增加消耗会违反ROI约束

**解决**：检查产品效率，改善后再分配

### Q3: 如何添加新的节假日？

编辑 `holiday_identifier.py` 的 `_build_holiday_calendar` 方法：

```python
holidays[datetime(2026, 5, 20)] = {
    'name': '自定义假期', 
    'scale_factor': 1.5,  # 改成你需要的倍数
    'type': 'custom'
}
```

### Q4: 系统支持哪些版位？

**当前**：按产品级建模（商店、联盟、智能投放一起考虑）

**改进方向**：可以扩展为版位级建模

### Q5: 历史数据用到了什么？

```
CSV数据的关键列：
- 日期：投放日期
- 消耗金额：花费
- 首日广告收入：D1回收
- 3日/7日/30日累计：后续回收
- 广告主ID：产品标识
```
