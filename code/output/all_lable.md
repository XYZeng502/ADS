# 智能预算决策系统 - 报告字段词典

生成时间：2026-05-06 21:40:08

系统每次运行生成 7 类输出文件，分别对应日汇总、优化摘要、预测明细、分配明细、月度汇总等。

---

## 一、`daily_report_*.csv`

按产品输出的日级诊断与预算建议表。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 日期 | date | 报告对应日期。 |
| 产品ID | str | 产品唯一标识。 |
| 等级 | str | 产品分级，当前取值 `A` / `B` / `C` / `-`。 |
| 优化器状态 | str | 当前预算优化模式，当前为 `RecoveryBudget`。 |
| 求解器状态 | str | 求解结果，当前为 `RECOVERY_INFEASIBLE`。 |
| D1回收率(历史) | float | 产品历史加权 D1 回收率。 |
| D1回收率(ML预测) | float | 模型预测的 D1 回收率。 |
| ML vs 历史差值 | float | `D1回收率(ML预测) - D1回收率(历史)`。 |
| D1预测P20(分配单元加权) | float | 分配单元加权后的 D1 P20。 |
| D1预测P50(分配单元加权) | float | 分配单元加权后的 D1 P50。 |
| D1预测P80(分配单元加权) | float | 分配单元加权后的 D1 P80。 |
| 达标D1 | float | 达成 KPI 所需的最低 D1。 |
| 当前ROI | float | 当前月内 ROI。 |
| KPI | float | 目标 ROI。 |
| ROI缺口(pp) | float | `KPI - 当前ROI`，单位 pp。 |
| 组合预测ROI_P20 | float | 组合口径下的 ROI_P20。 |
| 组合预测ROI_P50 | float | 组合口径下的 ROI_P50。 |
| P20安全垫(pp) | float | `组合预测ROI_P20 - KPI`，单位 pp。 |
| 恢复模式基准ROI | float | 恢复模式下的基准 ROI。 |
| 恢复预算上限 | float | 恢复模式可释放预算上限。 |
| 可选恢复预算段 | int | 可选恢复预算段数量。 |
| 累计消耗 | float | 截止当前的累计消耗。 |
| 累计回收 | float | 截止当前的累计回收。 |
| 活跃天数 | int | 当月有消耗的天数。 |
| 历史日均消耗 | float | `累计消耗 / 活跃天数`。 |
| 建议日均预算 | float | 推荐的日均预算。 |
| 分配总额 | float | 本次分配预算总额。 |
| 分配单元数 | int | 被分配的单元数。 |
| 分配覆盖日期数 | int | 覆盖的日期数。 |
| 分配Cap | float | 分配后的预算上限。 |
| Cap使用率 | float | `分配总额 / 分配Cap`。 |
| 分配预算占总建议 | float | `分配总额 / 建议日预算`。 |
| 分配单元P20边际ROI | float | 单元级 P20 边际 ROI。 |
| 分配单元P50边际ROI | float | 单元级 P50 边际 ROI。 |
| LTV倍率(分配加权) | float | 分配加权后的月内 LTV 倍率。 |
| 恢复提升分(分配加权) | float | 恢复模式带来的提升分。 |
| 分配质量分(分配加权) | float | 分配质量评分。 |
| 风险预算折扣 | float | 风险折扣系数。 |
| 风险预算动作 | str | 风险预算动作。 |
| 调优方向 | str | 调优建议方向。 |
| 改善可行性 | str | 是否具备改善可行性。 |
| 剩余改善天 | int | 剩余可改善天数。 |
| 临近截止 | str | 是否临近截止。 |
| 风险告警 | str | 风险告警说明。 |
| 诊断说明 | str | 诊断结论文本。 |
| 等级判定依据 | str | 等级判定的依据说明。 |

## 三、`validation_prediction_detail_*.csv`

单条样本的预测验证明细。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 日期 | date | 验证日期。 |
| 产品ID | str | 产品标识。 |
| 推广流量 | int | 推广流量编码。 |
| 流量场景 | int | 流量场景编码。 |
| 创意规格 | int | 创意规格编码。 |
| 转化类型 | int | 转化类型编码。 |
| 消耗 | float | 当日消耗金额。 |
| 实际D1 | float | 当日真实 D1。 |
| 模型P20 | float | 模型预测 P20。 |
| 模型P50 | float | 模型预测 P50。 |
| 模型P80 | float | 模型预测 P80。 |
| 产品均值基线 | float | 产品历史均值基线。 |
| 模型绝对误差 | float | `abs(模型P50 - 实际D1)`。 |
| 基线绝对误差 | float | `abs(产品均值基线 - 实际D1)`。 |

| P80命中 | int(0/1) | `实际D1 <= 模型P80`。 |
| P20_P80区间命中 | int(0/1) | `实际D1` 是否落在 `[P20, P80]`。 |
| P20保守余量 | float | `模型P20 - 实际D1`。 |
| P50误差 | float | `模型P50 - 实际D1`。 |

## 七、关键口径

| 概念 | 定义 |
| --- | --- |
| D1 | 首日回收率 = 首日广告收入 / 消耗金额。 |
| LTV倍率 | 月内回收倍率，用于把 D1 外推到月末。 |
| P20/P50/P80 | 分位数预测，分别对应保守、中性、乐观。 |
| KPI | 目标 ROI，当前为 `1.05`。 |
| ROI缺口(pp) | `KPI - 当前ROI`。 |
| 分配单元 | 产品 + 推广流量 + 流量场景 + 创意规格 + 转化类型。 |
| `新算法P20排序` | 按模型 P20 边际 ROI 排序。 |
| `产品均值基线` | 按产品历史 D1 排序。 |
