# 强交互可视化看板

## 入口

- `GET /web`

## 位置

- `app/web.py`

## 本次升级能力

- 一键触发离线回放（应用最后一天 / 全量回放）
- 多维筛选（应用ID、广告主ID、日期、展示上限）
- 动态指标卡（样本、ROI、预算、告警、模式分布）
- 图表面板（模式分布、ROI对比、偏差主因）
- 阶段成果对比（启发式 vs 联合求解v1 vs 调优版）
- 明细表实时刷新（客户端筛选）

## 看板页签

- 核心指标：运营当日判断（是否放量/守护）
- 阶段成果对比：展示 P0 迭代成效
- 明细数据：定位问题样本与动作建议

## 适用场景

- 算法同学：验证策略迭代收益
- 优化师：查看当日建议与风险
- PM：汇报阶段进展（可截图+导表）

## 后续增强建议

- 增加“单应用时序详情弹窗”（近14天信号拆解）
- 增加“规则命中明细图层”（可按 rule_id 过滤）
- 增加“多方案并排回放”（同日多参数对照）
