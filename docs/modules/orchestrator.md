# 编排模块（DailyOrchestrator）

## 位置

- `app/services/orchestrator.py`

## 职责

- 串联日历识别、预算求解、月末预测、风险诊断、规则命中。
- 输出 `DailyPlanResponse`，作为运营每日执行的主报文。

## 输入

- `ClientContext`
  - 当日日期、月内累计消耗/回收、KPI、昨日消耗、产品/槽位状态等。

## 输出

- `DailyPlanResponse`
  - 月末ROI预测、总规模预测、分产品分版位预算建议、D1目标、历史回收估计、风控告警、规则命中、诊断等。

## 当前流程

1. 识别 `day_type` 与 `scale`（日历模块）
2. 调用联合求解器输出今日预算建议
3. 估计当日历史回收
4. 预测月末 ROI/规模
5. 生成风控告警与产品诊断
6. 生成规则命中（可解释）
7. 汇总为统一响应

## 已落地价值

- 实现“每日滚动重算”主循环。
- 响应结构完整覆盖文档 5.1 关键字段。

## 待优化

- 增加“规则冲突合并器”，输出唯一最终动作。
- 增加“策略版本号”与“求解可行性状态”字段，便于审计。
