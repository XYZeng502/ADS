# 风控与诊断模块（RiskService）

## 位置

- `app/services/risk.py`
- `app/services/signal.py`（D1 信号融合）

## 职责

- 检测产品层表现异常（如 D1 连续下滑）
- 检测流量层异常（当日回收偏离）
- 产出 A/B/C 诊断分层与动作建议

## 核心逻辑

- `resolve_product_d1_signal`：
  - 优先融合近期真实值与预测值
  - 样本不足时回退到槽位加权预测
- 诊断分层：
  - 与 KPI gap 比较，输出 A/B/C 级别
  - 对应动作倾向：放量/稳态/收缩

## 输出

- `RiskAlert[]`
- `ProductDiagnosis[]`

## 已落地价值

- 风险与诊断统一接入主编排，不再是离散脚本分析。

## 待优化方向

- 接入“异常根因标签”（创意疲劳、流量结构、竞价变化）。
- 增加告警抑制窗口（防止连续重复告警）。
